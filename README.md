# プライバシーポリシー

当アプリ「奇門遁甲 羅針盤」におけるユーザー情報の取り扱いについて、以下のとおり定めます。

## 1. 取得する情報および利用目的
- **位置情報**: 本アプリでは、吉方位マップの展開および現在地を中心とした方位計算の目的でのみ位置情報（GPS）を使用します。位置情報は端末内での計算・表示にのみ使用され、外部サーバーに保存・送信されることはありません。
- **広告配信**: 本アプリでは、広告配信ツールとして Google AdMob を使用しています。Google AdMob は広告配信のために広告ID等の情報を収集する場合があります。詳細は Google のプライバシーポリシーをご確認ください。

## 2. 個人情報の第三者提供
当アプリは、法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供することはありません。

## 3. 免責事項
本アプリが提供する方位計算や鑑定結果は、その効果や特定の利益を保証するものではありません。本アプリの利用により生じた損害について、開発者は一切の責任を負いかねます。

## 4. お問い合わせ
本ポリシーに関するお問い合わせは、ストア掲載の開発者連絡先までお願いいたします。
